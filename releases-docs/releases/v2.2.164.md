### New Features

- **pnpm v12** — Bit's package manager internals are migrated to pnpm v12, now running through the `@pnpm/napi` Rust engine, which also renders install output, answers `bit why` and owns the lockfile (#10508, #10653)
  - Opt-in support for pnpm's global virtual store (#10582)
  - `bit install --restore` rebuilds the lockfile from the components' dependency graphs (#10325)
  - A repeat install that is already up to date is skipped by the engine (#10720)
- **`bit ci sync`** — bi-directional sync between Bit lanes and git branches/PRs (#10541)
  - Sync cross-scope lanes by mirroring the workspace-scope slice (#10644)
  - PR run summary, with convergence decided from a status probe (#10581)
  - Support GitHub Enterprise Server via `GITHUB_API_URL` and `GITHUB_SERVER_URL` (#10817)
  - `bit ci sync --init` writes the sync rules for agents into `AGENTS.md` (#10835)
- **Redesigned changes & compare experience** — single-component compare, lane compare and the workspace/lane overviews share one bulk-fetched implementation, the Monaco code diff is replaced with a lean Shiki-based viewer, and the semantic API diff is a first-class view (#10378, #10708, #10716, #10825)
- **Workspace-root component** — a component can live at the workspace root (`rootDir: "."`), with a new `trackAllFiles` flag (#10698)
- `bit gc` removes unneeded objects from the local scope (#10714)
- `bit ripple simulate` and `bit lane updates` commands (#10712)
- Hidden peer dependencies (#10066)
- Introduce the `empty-env` core aspect (#10535)

### Performance

- Bundle both UI roots in one compilation and shrink the UI pre-bundle from 58MB to 16MB (#10628, #10629, #10637)
- Enable Node's built-in compile cache on startup, and stop loading `hard-link-directory` on every invocation (#10669, #10599)
- Drop the `lsof` port pre-flight from server-routed commands (#10673)
- Reduce memory usage during snap on large workspaces (#10862)
- Bound the objects cache by bytes instead of count, and read flattened dependencies lazily from a separate object (#10723, #10758)
- Speed up export of components with many objects (#10745)
- Faster version lookups: index version lookups in history walks and export, index version parents by hash, look up a single tag without copying all versions, speed up the ref-to-tag lookup, and use a set in `VersionHistory.merge` (#10869, #10865, #10739, #10753, #10868)
- Filter objects by type from their header when listing the repository (#10730)
- Copy small Source contents out of the shared inflate buffer (#10785)
- Skip needless deep copies when hashing and converting versions (#10741)
- Look up `.bitmap` components by name instead of scanning all of them (#10742)
- Reuse evicted components that are still in use (#10736)
- Batch, dedupe and bound dependency imports when building graphs from the filesystem (#10635)
- Let pnpm reuse the lockfile across installs, install without a `readPackage` hook, and filter the lockfile in memory when calculating the dependency graph (#10748, #10787, #10854)
- Avoid loading removed components and their envs on `bit remove` (#10836)
